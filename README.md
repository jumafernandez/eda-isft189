# Práctica Profesional: Análisis y Exploración de Datos (ISFT N°189)

Material de la cursada, publicado con Quarto en https://jumafernandez.github.io/eda-isft189/

- `guia-fastapi.qmd`: guía práctica para persistir un modelo, servirlo con FastAPI y consumirlo desde HTML.
- `modelo-api/`: código de ejemplo de esa guía (Wine Quality).
- `guia-dockerfile.qmd`: guía práctica para crear un Dockerfile de la API del modelo.
- `proyecto/`: código de ejemplo (FastAPI, Flask y Docker Compose).
- `guia-integracion.qmd`: guía práctica sobre las formas de aprovechar un modelo publicado como servicio (clave de acceso, CORS, siete escenarios de uso, pruebas y despliegue).
- `integracion/`: código de ejemplo de esa guía. Un modelo y una API aprovechados en siete escenarios (consulta individual, lote, widget en un sitio ajeno, exploración, automatización, ficha del modelo y conversación), con pruebas y documentos.
- `render.yaml`: descripción de los servicios de `integracion/` para desplegarlos en Render.

Para renderizar localmente: `quarto preview`.
